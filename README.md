# Interview-coach
It's an AI web app for preparing for interviews as it will give you all the questions they will ask;
when you type what role and job will you be doing in the chat.
# What does it do ?
  1.Run mock interviews
  2.Ask follow up questions
  3.Analyse user's answers 
  4.Gives Feedback 
  5.Tracks interview progress
# It's Artificial Intelligence conversation + Evaluation
